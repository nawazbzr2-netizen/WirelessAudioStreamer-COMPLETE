# Wireless Audio Streamer

Android app for low-latency system audio streaming between phones over WiFi / Hotspot / Bluetooth.

## Features
- System audio + mic capture
- Camera streaming (optional)
- PIN security
- Remote control & file browser
- Urdu + English UI
